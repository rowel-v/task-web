# My Task

My Task is my first full-stack portfolio project. It’s a personal task manager built with Angular, Spring Boot, and PostgreSQL.

[Live demo](https://task-web-pva7.onrender.com) · [Spring Boot API repository](https://github.com/rowel-v/task-api)

## Features

- Create an account and sign in.
- Create and edit tasks, set priorities and due dates, and archive completed tasks.
- See today’s and upcoming tasks on the dashboard.
- Customize your profile, theme, and time zone.

## Deployment

The Angular frontend and Spring Boot API run on Render. Neon hosts the PostgreSQL database that stores user accounts and tasks.
